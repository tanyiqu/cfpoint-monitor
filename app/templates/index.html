Webhook 推送

企业微信填 https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...
机器人安全设置选「加签」时填写，会自动拼接 timestamp / sign
可用变量：{{event}} {{title}} {{message}} {{account}} {{role}} {{before}} {{after}} {{delta}} {{delta_text}} {{cfpoint}} {{time}}。内容若是合法 JSON 会按 JSON 发送。

连续失败 次后推送

                  秒（最小 20 秒，建议不低于 60 秒）
                

                
所有启用账号会按此间隔依次采集，账号之间还有 1~3 秒随机间隔，实际一轮耗时 = 间隔 × 账号数。

              


              

                
                
                
每次间隔上下浮动，避免固定节奏被风控识别

              


              

                
                
              


              

                
                
              


              

                
                
暂停期间不会请求接口，配置与账号都会保留

Cookie 保活

            
          

          

            

              

                
                
                
建议 10~20 分钟。每次心跳会用该账号 Cookie 访问一次活动页，刷新服务端会话活跃时间

              

              

                
                

                  · 固定浏览器指纹（UA / Referer / Origin / Accept）

                  · 定期 GET 活动页，模拟真人重新打开页面

                  · 间隔随机抖动，账号之间串行且有停顿

                  · Cookie 失效后自动降速，避免触发风控

                  · 记录 Cookie 使用时长，界面提示更换时机
                

              

            

          

          

            改动保存后立即生效
            

            
          

        


        

          
如何获取 Cookie

          

            
    
              
  1. 用目标账号登录 https://cf.qq.com/cp/a20241022query/page.html?type=9
    2. 
              
  2. 按 F12 打开开发者工具，切到 Network，筛选 ide
    3. 
              
  3. 点开对 cf.ams.game.qq.com/ide/ 的 POST 请求
    4. 
              
  4. 在 Request Headers 里找到 Cookie，整行复制
    5. 
              
  5. 回到本页「账号管理 → 添加账号」，粘贴进 Cookie 输入框即可
    6.
